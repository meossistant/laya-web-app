Air-Gapped & Offline Deployment Guide

1. Architecture Overview

Unlike autoregressive token-by-token LLMs, Laya operates as a fast System 1 model that evaluates state representations in a single forward pass (~33ms to ~65ms). It uses three primary checkpoints:

  • convaiinnovations/laya: English root (ModernBERT-large, 421M params, context 512).
  • multilingual: Multilingual model (mmBERT-base, 322M params, Vietnamese and 100+ languages, context up to 8k).
  • typed-decisions: Workflow-optimized checkpoint for classification, routing, and guardrails.

2. Downloading Models on a Networked Host

# Download all checkpoints locally:
python download_models.py --output-dir ./models/laya --checkpoint all

# Or download OpenVINO packages from Google Cloud Storage:
gcloud storage cp "gs://meolab-laya-models/*int8.tar.gz" ./models/openvino/
cd ./models/openvino && tar -xzvf multilingual_int8.tar.gz

3. Transferring to Air-Gapped Environment

# Pack web app and local models:
tar -czvf laya_airgap_package.tar.gz ./models/ ./app/ pyproject.toml run.sh

# Extract on destination offline host:
tar -xzvf laya_airgap_package.tar.gz -C /opt/laya-web-app/

4. Offline Execution

export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export LAYA_MODEL_PATH=/opt/laya-web-app/models/openvino

./run.sh
