📖 Hướng dẫn tải Model & Triển khai trong môi trường Offline

1. Tổng quan kiến trúc Offline của Laya

Khác với các LLM tự hồi quy sinh văn bản (autoregressive), Laya là mô hình System 1 không sinh text mà trả về trực tiếp các quyết định (Choice, Score, Noul) với độ trễ ~33ms. Khi tải về local, Laya gồm 3 checkpoint:

  • convaiinnovations/laya (Thư mục gốc): Model tiếng Anh (ModernBERT-large, 421M params, context 512).
  • multilingual: Model đa ngôn ngữ (mmBERT-base, 322M params, hỗ trợ tiếng Việt và 100+ ngôn ngữ, context tới 8192).
  • typed-decisions: Model chuyên sâu cho phân loại ticket, bảo mật, CS, agent traces (acc 0.766).

2. Cách tải toàn bộ model về local (trên máy có internet)

Sử dụng script Python kèm theo đã được tối ưu:

# Tải tất cả 3 checkpoint về thư mục ./models/laya
python download_models.py --output-dir ./models/laya --checkpoint all

# Hoặc tải bằng bash script:
bash download_models.sh ./models/laya

# Hoặc dùng huggingface-cli:
huggingface-cli download convaiinnovations/laya --local-dir ./models/laya --local-dir-use-symlinks False

3. Đóng gói và chuyển sang máy không có internet (Air-gapped)

# Bước 1: Nén thư mục model trên máy có mạng
tar -czvf laya_models_offline.tar.gz ./models/laya

# Bước 2: Chép file laya_models_offline.tar.gz sang máy offline (USB/Ổ cứng di động/NFS)

# Bước 3: Giải nén trên máy offline
tar -xzvf laya_models_offline.tar.gz -C /opt/laya-web-app/

4. Khởi chạy Web App trong môi trường không có internet

# Thiết lập các biến môi trường ngắt kết nối tuyệt đối
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export LAYA_MODEL_PATH=/opt/laya-web-app/models/laya

# Khởi chạy ứng dụng
python -m app.main

Giao diện web app sẽ tự động nhận diện weights tại thư mục local và chạy với 0 byte internet transfer!
